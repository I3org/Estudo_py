# Estudos de Python 🐍

Este repositório contém os exercícios, códigos e anotações desenvolvidos durante a graduação para o aprendizado da linguagem Python.

## 📁 Conteúdo do Repositório
- **`aula1.py`**: Conceitos básicos, entrada de dados (`input`), conversão de tipos (`int`)

- **`aula2.py`**: Estruturas condicionais compostas (`if/elif/else`)

## Objetivo
Servir como histórico de estudo, prática e evolução técnica.
